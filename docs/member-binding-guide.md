# 會友綁定說明（給試跑同工／會友）


「綁定」就是把**你的 LINE 帳號**和**教會名冊上的你**接起來。綁定完成後，你才能在手機上查自己的車位狀態、確認遞補的車位，也才收得到系統的 LINE 通知。

---

## 開始前你需要

- 一支能用 LINE 的手機
- **你留給教會的那支手機號碼**——系統是靠這支號碼把你對到名冊上的，留錯號碼會對不到人
- 你在教會登記的姓名

---

## 四個步驟

### Step 1️⃣ 先加入教會官方帳號（OA）好友

**這一步一定要做，而且建議放在最前面。** 沒有加好友，系統就沒有辦法推播任何訊息給你——你可以綁定成功、可以有車位，但**所有 LINE 通知都會送不出去**。

加入方式：**掃描教會提供的 QR code**，或點教會發給你的官方帳號連結（見發給你的說明頁／現場立牌）。

加好友之後，畫面上不會有任何反應（系統不會自動回覆），這是正常的，請直接進行 Step 2。

### Step 2️⃣ 進入「會友專區」

點教會官方帳號下方**選單**的「**停車申請**」，或點教會提供的連結／現場 QR code。

> 📱 **連結請在 LINE 裡面點**。用相機掃、或複製到 Safari／Chrome 開，會走另一條登入流程，可能卡在「連線中」。

第一次進入時，LINE 會跳出**同意畫面**。

> ⚠️ **同意畫面上如果有「加入好友」的勾選，請保持勾選、不要取消。**

### Step 3️⃣ 填姓名 + 手機，送出申請

會看到「**申請綁定會友專區**」的表單，填兩個欄位：

| 欄位 | 填什麼 |
|---|---|
| 姓名 | 你在教會登記的姓名 |
| 手機號碼 | `09` 開頭共 10 碼，不用加橫線 |

按「**送出申請**」，看到綠色的「**已送出綁定申請**」就成功了。

### Step 4️⃣ 等同工核准

申請送出後，**由教會停車管理同工人工核對名冊再核准**，不是立刻生效。

> 📌 **核准後不會另外通知你**。隔一段時間再打開會友專區看看：如果直接看到你的車位狀態（不再是那張申請表單），就代表已經核准、綁定完成了。

---

## ⚠️ 綁定完，請自己確認一次「有沒有加到好友」

因為這件事錯了不會有任何提示，請自己檢查：**打開 LINE 的聊天／好友清單，看得到教會官方帳號嗎？**

- **看得到** → 沒問題 ✅
- **看不到** → 現在補加好友就好。

**特別注意**：如果你曾經**封鎖**過教會官方帳號，效果跟沒加好友一樣，通知一樣送不到。請解除封鎖。



---

## 備用路徑：用「綁定碼」

如果自助表單走不通（例如手機號碼跟教會名冊上的對不起來），Admin 可以直接發一組**一次性綁定碼**給你。拿到之後：

在**教會官方帳號的聊天室**裡，傳一則訊息：

```
綁定 ABCD-2345
```

（把 `ABCD-2345` 換成你拿到的那組碼，大小寫都可以。）

傳出去之後**畫面上不會有任何回覆**，這是正常的——系統只負責把你的申請記下來，一樣要等同工核准。

---

## 🚗 綁定完成 ≠ 有車位：每一週都要自己登記一次

**這是最容易誤會的地方。** 綁定只是把你的身分接上系統；**車位要每一週重新登記**，沒登記就不會被分配到，系統也不會自動幫你沿用上週的。

### 一週的流程

| 時間 | 發生什麼 | 你要做什麼 |
|---|---|---|
| **週一 09:00** | 本週登記開放 | **進會友專區按「登記本週停車」** |
| 送出後 | 狀態變成「已登記，等待分配」 | 等，不用再做什麼 |
| **週五 18:00** | 系統自動分配車位 | **注意 LINE 通知**，或自己開會友專區看結果 |
| 週五 18:00 之後 | **線上登記關閉**（分配一開始就不再收新登記） | 沒趕上就不能線上登記了；臨時需要停車請依教會現場停車規則處理 |
| 週六～主日 | 有人取消 → 依候補順序遞補 | 候補中的人**要留意通知**（見下一節） |

### 怎麼登記

進會友專區 → 按「**登記本週停車**」→ 選你的**車輛**（車牌）→ 按「**送出登記**」。

- 如果你有**年長者同行**或**學齡前幼兒同行**的資格，表單上會多一個勾選框。**本週真的有同行才勾**，勾了這一次會排在比較前面的優先順序。
- 如果看到「**尚未登記車輛資料**」，代表系統裡還沒有你的車牌——**請聯繫停車同工登記車牌**，登記好才能線上登記停車。
- 想改車輛或不停了：按「**取消本週登記**」。**主動取消不算未到場、不計違規**——週五 18:00 前或之後（到主日 10:30）都一樣。週五之後取消還會馬上讓候補的人遞補上來，所以確定不來請盡早取消。

---

## 🔔 請留意 LINE 通知（有兩則有時限）

> 系統**只會透過教會 LINE 官方帳號通知**，不會發簡訊、也不會打電話。所以請確定你已加好友（見上面那節），通知才收得到。

登記之後，可能會收到這幾種訊息。開頭都是 **【教會停車】**：

| 什麼時候 | 訊息大概長這樣 | 你要做什麼 |
|---|---|---|
| 週五 18:00 分配後 | 「○月○日主日的停車申請**已核准**」 | 位子是你的了，主日準時到 |
| 週五 18:00 分配後 | 「車位已額滿，您目前**候補第 N 位**」 | 等遞補通知，或考慮其他交通方式 |
| 有人取消、遞補到你 | 「有一個停車名額**釋出給您**！⏰ 請於 ○○:○○ 前確認」 | ⚠️ **一定要在期限前，到會友專區按「確認保留車位」** |
| 主日凌晨（00:00）之後 | 「有名額釋出，**已為您自動保留**車位」或「停車申請**已核准**」 | 不用做任何事，直接來 |
| 主日 10:30（候補中的人） | 「現在有停車名額釋出，歡迎前往地下室」 | 想停的話直接去，**現場先到先停、不保證留位** |
| 主日 10:20（僅 P2） | 「您保留的車位將於 10:45 釋出」 | 已在路上請到會友專區回報「正在路上」 |
| 主日現場 | 「請車主移車」（同工發出） | 儘快到地下室移車 |

### ⏰ 需要你主動確認的那一則（候補遞補）

**「有一個停車名額釋出給您！請於 ○○:○○ 前確認」——這則有 2 小時的期限。**

過了期限沒確認，**這次**釋出的車位會順延給下一位候補；你的登記會**回到候補狀態並保留原本的順位**，之後如果又有人取消，仍然可能再輪到你。所以錯過一次不代表本週出局，但那一次的車位確實拿不回來了。

所以：**週五晚上到主日之間，如果你是候補，請養成主動打開會友專區看一眼的習慣**，不要只等 LINE 響。

### ⏰ 另一則有時限的：P2 的 10:20 到場提醒

如果你有 P2 優先資格、當週已核准但 10:20 還沒到，系統會提醒你**車位保留至 10:45**。若你已在路上，請到會友專區回報「**正在路上**」，保留時間可延長到 **10:55**（不會再無限延長）。

## 綁定完成之後，請記住三件事

1. **通知沒收到，不代表你沒有車位。** 車位是週五晚上分配時就寫進系統的，通知只是把結果告訴你。
2. **會員專區那一頁才是你的狀態依據**，LINE 通知只是提醒。這一頁不經過通知系統，所以通知壞掉時它照樣正確。**不確定的時候一律以會員頁為準。**
3. **候補的會友看到「已為您保留車位，請於 ○○:○○ 前確認」一定要在期限前按確認**——過了期限，那個車位會釋出給下一位候補（你會回到候補、保留原順位，之後仍可能再遞補）。所以請養成主動打開會友頁看的習慣，不要只等 LINE 響。

目前還是測試，主日請照舊規定停車

**也請幫忙回報**：該收到通知卻沒收到、通知內容怪怪的、畫面顯示跟實際不符——請回報給停車管理同工／試營運窗口。

## 給 Admin 的備註

- **這份 md 是 source of truth；`docs/member-binding-guide.html`（同目錄、未進版控）是本機維護的發送版。** HTML 為這份 md 的排版版，Step 1 直接內嵌教會官方帳號的**加入好友 QR code 與連結**，手機可掃、可點、可列印，單一檔案不需網路。
  - **教會的 OA 連結／QR 刻意不進 repo**：`.gitignore` 第 35 行的 `docs/*.html` 已涵蓋（同 [delivery-handbook.html](delivery-handbook.html) 的作法），所以 QR 只存在於本機那份 HTML 裡；這份 md 只寫「掃教會提供的 QR」。
  - **內容一律先改 md，再手動同步 HTML**（HTML 是手工排版，沒有自動產生器）⇒ **兩份長期必然 drift**，發送前請以 md 為準核對一次。QR 圖以 base64 內嵌，換 OA 時要重新產生。
  - **真人姓名／窗口不寫進這份 md**（repo 為 public，見 `.gitignore` 開頭的說明）。要寫具名窗口請只寫在 HTML 那份或現場說明。
- **發出去的連結一律用 LIFF URL（`https://liff.line.me/<LIFF_ID>`），不要發 `…vercel.app/member`。** 直接發網域有兩個問題：① 少了 LIFF 的 `Add friend On (Normal)` 動線，同意畫面不會帶「加入好友」勾選 → 綁得成功但**通知推不出去**；② 換網域時每個貼過的連結都要追回來（印出去的 QR 追不回來），LIFF URL 則只要改一處 Endpoint。`<LIFF_ID>` 取自 Vercel Production 的 `NEXT_PUBLIC_LIFF_ID`，見 [member-liff-setup.md](member-liff-setup.md)；實際值只寫在 HTML 那份（未進版控），比照 OA 連結的作法。
  - **已經拿舊網址綁定的人不用重綁**：`line_id` 來自同一個 LINE Login channel 驗過的 ID token，userId 一致，推播照樣推得到。要補查的只有「有沒有加好友」——跑 `npm run job:outbox-status` 看 `failed_by_error.terminal_403`（已綁定但沒加好友／已封鎖），見 [dispatcher-ops.md](dispatcher-ops.md)。
- 這份文件可以整份轉給試跑同工，或只截「四個步驟」＋「常見狀況」兩段貼到 LINE 群組。
- 「綁定完成之後，請記住三件事」與 [admin-operations-guide.md](admin-operations-guide.md) §4「給試跑同工的說明」是同一套話術，兩邊要改請一起改。
- **LIFF 自助申請不會主動通知你有人申請**，要看 `/admin/bindings` 才知道，見 [binding-ops.md](binding-ops.md)。所以 Step 4 的「等很久沒核准」在實務上是真的會發生的——建議放行前先講好由誰、多久檢查一次待審清單。
  - ⚠️ 本文提到的 `npm run binding:pending`／`job:outbox-status` 等 CLI **目前無法用 `npm run` 直接啟動**（`server-only` 與 `tsx` 的相容問題，2026-07-30 起）；繞行指令與影響範圍見 [binding-ops.md](binding-ops.md) 的「審核入口」註記。**`/admin/bindings` 這條主要路徑不受影響。**
- **退回（reject）不會通知會友**，他們只會看到表單還在。退回後請主動聯繫本人。
- 提高加好友比例的具體做法（歡迎訊息、圖文選單、現場 QR），見 [oa-onboarding-and-move-car-copy.md](oa-onboarding-and-move-car-copy.md)。
- 若出現大量 `terminal_403` 失敗，代表「已綁定但沒加好友／已封鎖」，重送前必須先讓對方加回好友，見 [dispatcher-ops.md](dispatcher-ops.md)。

## 常見狀況

| 你看到 / 遇到 | 意思 | 怎麼辦 |
|---|---|---|
| 送出後重新打開，又出現空白表單 | **正常**，申請沒有不見（頁面不會記住你剛剛送過） | 不用重送；真的要改資料才重填一次 |
| 想改剛剛填錯的資料 | 重送會直接覆蓋掉舊申請，不會變成兩筆 | 按「修改重送」，或重新填一次送出 |
| 「資料格式有誤，請檢查姓名與手機號碼」 | 手機格式不對 | 確認是 `09` 開頭、共 10 碼、沒有空白或橫線 |
| 「登入已過期，請關閉此頁後重新開啟」 | LINE 的登入憑證過期了 | 完全關掉這一頁，再從選單重新進入 |
| 「連線驗證服務失敗，請再試一次」 | 暫時連不上 LINE 的驗證服務 | 稍等一下再送一次 |
| 「發生錯誤，請稍後再試」 | 未預期的錯誤 | 稍後再試；一直發生就回報 Admin |
| 「此帳號已完成綁定，正在為您登入…」 | 你這個 LINE 帳號已經綁過了 | 不用做任何事，它會直接帶你進去 |
| 等了很久都沒核准 | 沒有通知可以提醒你，而且可能是姓名／手機跟名冊對不上 | **主動聯絡 Admin 或小組長**確認 |
